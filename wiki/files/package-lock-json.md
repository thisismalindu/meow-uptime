# `package-lock.json` — npm dependency snapshot

This 936-line JSON file is **generated by npm**. Its code is dependency metadata, not handwritten application logic. Reproducing every registry URL and integrity hash here would create a stale second lockfile, so this page includes its meaningful shape and explains every kind of line npm generates. The real file remains the exact source of truth.

## Representative source from the top

```json
{
  "name": "meow-uptime",
  "version": "0.1.0",
  "lockfileVersion": 3,
  "requires": true,
  "packages": {
    "": {
      "name": "meow-uptime",
      "version": "0.1.0",
      "dependencies": {
        "@supabase/supabase-js": "^2.112.3",

      }

      "version": "2.112.3",

      "integrity": "sha512-...",
      "license": "MIT",

        "tslib": "2.8.1"
      },

        "node": ">=22.0.0"
```

The integrity value is shortened only in this explanation; never shorten or manually modify it in the real lockfile.

## How to understand every generated entry

- Top-level `name` and `version` mirror `package.json`.
- `lockfileVersion: 3` identifies npm's current lockfile data format.
- `requires: true` says this project has dependencies.
- `packages` maps an install location to the exact package metadata installed there.
- The empty-string package key represents this root project.
- A key such as `node_modules/express` represents one installed dependency location.
- `version` pins the exact release, removing ambiguity from the caret ranges in `package.json`.
- `resolved` records the package archive location.
- `integrity` is a cryptographic checksum npm uses to detect corrupted or altered downloads.
- `license` reports the dependency's declared license.
- Nested `dependencies` are packages required by that package; these are **transitive dependencies** because the app did not list them directly.
- `engines.node` declares supported Node versions. The locked Supabase packages require Node 22 or newer.
- `optional`, `peer`, `peerDependencies`, and `peerDependenciesMeta` describe conditional or host-package relationships when they appear.

Repeated closing braces and commas only close these nested JSON objects. The same vocabulary explains the remaining hundreds of lines for Supabase's subpackages, Express's middleware dependencies, and their dependencies.

## Why commit it?

`npm ci` reads this file to reproduce exact dependency versions in CI and Docker. Commit lockfile changes produced by intentional npm operations. Do not hand-edit it; use commands such as `npm install <package>` and review the generated diff.

The repository's npm lock resolves Express to 4.21.2. The separate pnpm lock currently resolves it differently, which is one reason to standardize on one package manager.
